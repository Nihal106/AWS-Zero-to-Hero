# AWS CloudWatch — AWS Service Monitoring

CloudWatch integrates with many AWS services.

## EC2

- CPU
- Network
- Disk operations
- Status checks
- Memory using CloudWatch Agent

## RDS

- CPU
- Connections
- Storage
- IOPS
- Read/write latency

## ALB

- Request count
- Target response time
- HTTP 4XX
- HTTP 5XX
- Healthy targets

## Lambda

- Invocations
- Errors
- Duration
- Throttles
- Concurrent executions

## ECS

- Tasks
- Services
- Containers
- CPU
- Memory
- Application logs

## EKS

CloudWatch can provide:
- Cluster monitoring
- Node monitoring
- Pod/container monitoring
- Logs
- Container Insights

## API Gateway

- Requests
- Latency
- 4XX
- 5XX

## Learning Goal

Understand which CloudWatch metrics are useful for each AWS service.
