# AWS CloudWatch — Introduction

Amazon CloudWatch is an AWS monitoring and observability service used to monitor AWS resources, applications, infrastructure, logs, metrics, and operational events.

## Why Do We Need CloudWatch?

Without monitoring:

Application → Problem → User reports issue

With monitoring:

Application → Metrics / Logs → CloudWatch → Alarm → Notification → DevOps Engineer

## Major CloudWatch Features

- Metrics
- Logs
- Logs Insights
- Alarms
- Dashboards
- Metric Filters
- Custom Metrics
- CloudWatch Agent
- Container Insights
- Application monitoring
- Synthetics
- EventBridge integration

## CloudWatch vs CloudTrail

CloudWatch:
- Monitoring
- Metrics
- Logs
- Alarms
- Application observability

CloudTrail:
- API activity
- AWS account activity
- Auditing

## Learning Goal

Understand what CloudWatch is, why it is used, what it monitors, and its main components.
